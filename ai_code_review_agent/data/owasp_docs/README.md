# Secure Coding Knowledge Base -- source documents

Drop OWASP / secure-coding reference material here, then use the
**Knowledge Base** tab in the app (or `python -c "from rag.ingest import build_or_refresh_index; build_or_refresh_index()"`)
to chunk, embed, and index it for the RAG-grounded Security Agent and
Conversational Assistant.

Supported formats: `.pdf`, `.md`, `.txt`.

Good sources to add (download the official PDFs/pages yourself):
- OWASP Top 10 (owasp.org/Top10)
- OWASP Application Security Verification Standard (ASVS)
- OWASP Cheat Sheet Series (SQL Injection Prevention, XSS Prevention,
  Authentication, Secrets Management, etc.)
- Your organization's internal secure-coding standard, if you have one

This folder starts empty on purpose -- OWASP's PDFs are copyrighted
documents redistributed by OWASP itself, so this project does not ship
copies. Download them from owasp.org and place them here.
